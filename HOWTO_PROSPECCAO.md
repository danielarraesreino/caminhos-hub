# 📣 HOW TO: Prospecção & Captação (Para o Juliano)

Juliano, seu foco é abrir portas. O projeto tem uma história única que facilita muito a conexão emocional e técnica.

## 1. Onde Prospectar
Foque nos órgãos que já têm agenda aberta para Pop. Rua:
- **IPEA**: Eles precisam de dados qualitativos. Aborde com o "Resumo Executivo".
- **Secretarias de Assistência Social**: Foque em capitais (SP, BH, Curitiba, Porto Alegre). O argumento é: "Temos uma ferramenta que ajuda a gerir e dar autonomia, baseada em vivência real".
- **Fundações**: Tide Setúbal é a prioridade #1 no Brasil para este tema.

## 2. Como Usar os Materiais
1. **E-mail Frio**: Use o [Template de E-mail](templates/email_prospeccao_prefeituras.md). Personalize o nome do secretário(a).
2. **Follow-up**: Se não responderem em 3 dias, mande um "Oi, gostaria apenas de confirmar se o e-mail chegou".
3. **Reunião**: Na reunião, o Daniel entra para mostrar a parte técnica e a vivência, e você entra para fechar a parceria/acordo.

## 3. Gestão de Contatos
Use o Dashboard para marcar quem você já contatou. Se preferir, podemos criar uma tabela aqui mesmo no GitHub para CRM básico.
